If $0 ≤ x$ and $0 ≤ y$, then $0 ≤ x + y$, $|x + y| = x + y$, $|x| = x$, and $|y| = y$, so that equality holds in this case. If $x ≤ 0$ and $y ≤ 0$, then $x + y ≤ 0, |x + y| = −(x + y) = −x − y, |x| = −x$, $|y| = −y$, resulting in an equality. Now suppose one of the numbers is negative and the other positive, for example, $x < 0 < y$. Then either $x < x +y ≤ 0$ or $0 ≤ x +y < y$. In the first case $|x +y| < |x|$, and in the second case $|x + y| < |y|$, so that in both cases $|x + y| < |x| + |y|$.

\textbf{Q.E.D}
